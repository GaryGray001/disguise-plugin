## **🎉 v1.0.0 — Initial Release**

The complete disguise plugin is here — **86 mobs**, realistic mechanics, economy support and a fully multilingual UI.

---

### ✨ **New Features**

- **🎭 86 disguises** — animals, mounts, monsters, elite mobs and bosses (Ender Dragon, Wither, Happy Ghast)
- **📖 GUI menu** — categorized pages with color / size / baby sub-menus
- **🐔 Realistic mob mechanics** — chicken eggs, camel sit, armadillo scutes, breeze wind charges, shulker teleport, creeper explosion, warden sonic boom, flying boss animations
- **🏃 Authentic movement** — per-mob walk speeds, knockback resistance, fall immunity
- **💰 Economy (Vault)** — `admin` / `all` / `paid` modes, per-mob prices (100–1000), per-mob durations (default 30 min, auto-expire, free cancel)
- **🌍 Multi-language** — 简体中文 & English, custom language files supported
- **🔧 Commands** — `/dp`, `/dp reload`, `/dp debug`, `/dp mode` with tab completion

### ✅ **Compatibility**

- **Loaders**: Paper, Spigot, Purpur
- **Minecraft**: 1.21.0 – 1.21.11
- **Java**: 21 · **Vault**: optional

### 🐛 **Fixed**

- Crash on servers without Vault → now falls back gracefully
- Sheep / axolotl color menus not opening
- Full 1.21.x support — newer mobs auto-hidden on older versions
